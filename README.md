# 힘 단위 변환기

## 프로그램 용도

Tkinter 기반 GUI 프로그램으로, 입력한 힘의 값을 `kN`, `N`, `kgf` 단위 사이에서 변환합니다. 변환 결과는 소수점 셋째 자리까지 표시되며, 성공한 변환은 프로그램을 실행하는 동안 변환 기록 창에서 확인할 수 있습니다.

## 필요한 환경

- Python 3
- Tkinter가 사용 가능한 Python 환경

Tkinter는 파이썬 표준 라이브러리 모듈입니다. 설치 환경에 따라 Tk 지원이 별도로 제공되어야 할 수 있습니다.

## 실행 방법

PowerShell에서 이 폴더로 이동한 뒤 다음 명령 중 하나g를 실행합니다.

```powershell
python ".\202601703김상혁 (힘 단위 변환기).py"
```

Windows Python 실행기(`py`)를 사용하는 경우:

```powershell
py ".\202601703김상혁 (힘 단위 변환기).py"
```

## 입력 예시

값 입력 칸에 숫자를 입력하고 입력 단위와 출력 단위를 선택한 다음 **변환**을 누릅니다.

| 값 입력 | 입력 단위 | 출력 단위 | 표시 결과 |
| --- | --- | --- | --- |
| `2.5` | `kN` | `N` | `2.5 kN = 2500.000 N` |
| `10` | `N` | `kgf` | `10.0 N = 1.020 kgf` |

지원 단위는 `kN`, `N`, `kgf`입니다. 음수가 아닌 숫자를 입력할 수 있습니다.

## 오류 입력 예시

| 입력 | 표시 결과 |
| --- | --- |
| `abc` 또는 빈 값 | `단위를 변환할 수 없습니다.` |
| `-1` | `힘은 0 이상의 숫자로 입력하세요.` |

오류가 표시되면 값 입력 칸을 수정한 뒤 다시 **변환**을 누르세요.
